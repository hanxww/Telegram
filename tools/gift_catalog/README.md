# HaslGram — импорт метаданных оригинальных Telegram Gifts

Это отдельный инструмент для создания **каталога метаданных** по официальному API Telegram. Он НЕ переносит сами подарки, право собственности, официальные Stars, Premium или изображения/анимации на частный сервер HaslGram.

## Что позволяют api_id и api_hash

Эти параметры идентифицируют Telegram API-приложение. Они **не являются** ключами HaslGram, не заменяют логин Telegram-пользователя, не дают автоматически доступ к оплатам, медиафайлам или чужим аккаунтам. Требуется отдельная авторизованная Telegram-сессия с согласием её владельца.

Ссылка: https://core.telegram.org/api/obtaining_api_id

## Получение текущего каталога

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install 'telethon>=1.40'
read -rp 'TG_API_ID: ' TG_API_ID; export TG_API_ID
read -rsp 'TG_API_HASH: ' TG_API_HASH; echo; export TG_API_HASH
python3 tools/gift_catalog/export_telegram_catalog.py \
  --output private/telegram-gift-metadata.json \
  --attributes
unset TG_API_ID TG_API_HASH
```

Инструмент интерактивно авторизует Telegram-пользователя (если сохранённой сессии нет). **Никогда не публикуйте** `.session`, `.env`, `TG_API_HASH`, код подтверждения, JSON с приватной информацией и ключи в GitHub. Сессия по умолчанию создаётся в домашнем каталоге.

## Что есть в результате

- `telegram_gift_id`, `current_telegram_stars`, `upgrade_stars`, `sticker.id`.
- При запросе `--attributes`: варианты моделей, фонов, узоров и редкость в пределах данных, доступных официальному API.
- `launch_stars` **специально null** — API текущего каталога не подтверждает первоначальную цену исторических выпусков. Отдельно нужен проверяемый исторический источник и ручная верификация.
- Результат не содержит полные `access_hash` документов, сами стикеры и права на их использование.

Методы: https://core.telegram.org/api/gifts , https://core.telegram.org/method/payments.getStarGifts

## Граница самостоятельного HaslGram

Для настоящих покупок и улучшений внутри HaslGram требуется отдельная база, серверный движок Stars и Gifts, файлохранилище с допустимыми к использованию материалами, проверка владения, атомарное списание, защищённая генерация вариантов и Android UI. Нельзя просто отправлять запросы `payments.getPaymentForm` к Telegram и делать вид, что это покупки в HaslGram.

## Ограничения

- В зависимости от текущего TL-слоя Telethon метод получения вариантов может отсутствовать; обновите Telethon и убедитесь, что версия поддерживает этот метод.
- Отдельные атрибуты могут быть недоступны для некоторых подарков; экспорт явно отмечает ошибку.
- Скрипт не запускает покупки и не скачивает медиадокументы.
